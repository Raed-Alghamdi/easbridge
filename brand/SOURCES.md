# Sources and licences

## Wordmark font
- **JetBrains Mono Bold**, copyright JetBrains s.r.o., SIL Open Font License 1.1. https://github.com/JetBrains/JetBrainsMono
- Outlines were taken from a locally installed JetBrains Mono Nerd Fonts build (`JetBrainsMonoNerdFont-Bold.ttf`, and `-Regular.ttf` for the social preview tagline). Nothing was downloaded. Nerd Fonts only adds icon glyphs, so the Latin letters used (E, A, S, B, r, i, d, g, e and the tagline text) match upstream JetBrains Mono. The Nerd Fonts patched fonts keep the OFL 1.1 of the base font. This was not verified glyph by glyph against the upstream file.
- **Nerd Fonts patcher**: MIT licence, https://github.com/ryanoasis/nerd-fonts. It applies only to the patcher scripts, not to the outlines used here.
- Text is converted to SVG paths with fontTools 4.64 (`tools/final.py`), so no font file is needed to display or ship the logo. Outlines are a derived work, which the OFL allows. Include the OFL text only if the font file itself is ever shipped.

## Artwork
The arch mark, lockups and all variants are original geometric drawings generated by script. No third-party artwork, no AI images, no traced material.

## Tools
fontTools, librsvg (`rsvg-convert`), svgo 4.1.0, ImageMagick.
