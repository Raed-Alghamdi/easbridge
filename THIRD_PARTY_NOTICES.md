## The Go toolchain and standard library

The binary is built with Go 1.27 and contains the Go standard library and runtime, licensed under the Go BSD-3-Clause licence
(https://go.dev/LICENSE). The licence text is reproduced below.

## Container image

The image is built `FROM gcr.io/distroless/static-debian12:nonroot` (pinned by digest in the `Dockerfile`). That base contains
`ca-certificates`, `tzdata`, `base-files` and `netbase`; their licences are in `/usr/share/doc/<package>/copyright` inside the image and
on https://github.com/GoogleContainerTools/distroless. The builder stage uses `golang` (pinned by digest); nothing from it ships in the
final image except the compiled binary.

## Test-only software, not distributed

The npm packages that `compat/` and `e2e/` install (`imapflow`, `nodemailer`, `undici`, `fast-xml-parser` and their dependencies, listed
in `compat/package-lock.json`) are used only to test EASBridge. They are not part of the binary or the image and are not distributed
with this repository. The same is true of MailFlow's source files that the compatibility checks fetch at test time into a git-ignored
cache (MailFlow is AGPL-3.0): they are read and run, never copied into this repository. The `node:22-alpine` image used by `make e2e`
is likewise only a test dependency.
